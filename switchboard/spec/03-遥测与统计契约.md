# 03 遥测与统计契约

- 状态：规范性（Normative）
- 版本：1（遥测 schema 独立版本化）

遥测是可比性的前提（P3）：不吐统一遥测的模块无法进入 SB-Bench，也无法被码控消费。这是最低合规等级 L-A 的全部内容。

## 1. StageStats（JSON schema v1）

每个活跃连接、每个阶段 MUST 以 ≥1 Hz 或按需采样输出：

```jsonc
{
  "v": 1,
  "ts_ms": 1730000000000,
  "stage": "transport",              // discovery|punch|relay|transport|media|codec
  "module": "sb.quinn.quic",
  "conn": "b3f1…",                    // 连接 uuid
  "path": { "kind": "direct",        // direct|relay|loopback —— MUST 如实
            "local": "192.168.1.2:51000", "remote": "203.0.113.7:443" },
  "rtt_ewma_ms": 23.5,               // EWMA α=1/8（TCP 惯例，全规范统一）
  "loss_ratio": 0.002,               // 采样窗总丢失率（下三字段的聚合，兼容保留）
  "loss_rx": 0.001,                  // 接收侧 seq gap 估计（评审修订 #7）
  "loss_tx": 0.001,                  // 发送侧 ack 估计
  "drop_app": 0.0,                   // 应用层队列丢弃（队满弃帧/丢新包）
  "send_mbps": 8.1, "recv_mbps": 7.9,
  "queue_depth_bytes": 4096,         // 发送积压——码控拥塞信号
  "jitter_ms": 1.2,                  // RFC 3550 定义的 INTERARRIVAL_J，计算窗 = 采样窗
  "extra": { }                       // 模块私有扩展（QUIC: cwnd；FEC: 恢复成功率、recv_buffer_depth…）
}
```

规则：

1. 必填字段缺失 = 不合规模块（注册表校验拒绝）；`loss_rx/loss_tx/drop_app` 为 v0.1 SHOULD、v0.2 MUST（L-C 认证自 v0.2 起强制三分）；
2. `path.kind` 与实测不符（如中继谎报直连）= L-C 认证一票否决（SB-Bench T3 剖面用强制中继对照验证）；
3. `extra` 允许任意扩展，但消费方 MUST 只依赖必填字段。

## 2. 事件流（低频但必须）

```jsonc
{ "v":1, "event":"stage_transition", "from":"punch", "to":"transport", "outcome":"direct|relay|failed", "detail":{…} }
{ "v":1, "event":"frame_drop",       "count":3, "reason":"queue_full|decode_late", "stream":"video" }
{ "v":1, "event":"frame_rendered",   "frame_id": 1234, "ts_ms": 0 }   // 评审修订 #8：低频采样（≥1/10帧），M3/M4 数据源
{ "v":1, "event":"recovery",         "kind":"idr|ltr|tile|nack", "cost_ms": 45 }
{ "v":1, "event":"path_upgrade",     "from":"relay", "to":"direct", "gain_rtt_ms": 1100 }
```

资源占用（评审修订 #8）：S6 codec 阶段的 StageStats MUST 在 `extra` 中携带 `cpu_percent` / `gpu_encoder_percent`（04 篇 M10 数据源）。

## 3. 消费方

| 消费方 | 用途 |
|---|---|
| SB-Bench | 采样聚合出指标（04 篇），打分的唯一数据源 |
| 码控（media.control） | AIMD/QoS 规则的输入 |
| Studio HUD | 实时显示 fps/RTT/码率/路径（rd HUD 契约同构） |
| Plan 执行器 | 路径健康门控与升级判定（02 §2.2） |

## 4. 实现

SDK 提供 `TelemetryBus`（扇出、环形缓冲 10s、背压丢弃旧帧）。模块只管 `emit`，不许自行落盘——落盘由 bench/HUD 统一负责，保证口径一致。
