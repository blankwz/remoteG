## 约定
- Rust → TS 帧传递：`tauri::ipc::Channel<InvokeResponseBody>` 发送原始字节（`InvokeResponseBody::Raw`），TS 收到 `ArrayBuffer`；帧头格式同 05_api §3。
- 状态管理：React state + 每个会话一个 `SessionStore` 类（不引入 Redux）。
- 样式：纯 CSS Modules，不引 UI 库（M1）。
