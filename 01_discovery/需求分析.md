# 需求分析
- 状态：已确认（P0 已于 2026-10-13 第 1 轮答复）

## 1. 5W2H
| 项 | 内容 |
|---|---|
| What | 个人用窗口级远程控制工具：按窗口传输与操控，文字清晰，终端/Web 可结构化自绘 |
| Why | RustDesk 整屏传输在异分辨率/小屏（iPad、iPhone）上字小且糊；只需要操作某几个窗口 |
| Who | 用户本人（单用户，多台自有设备） |
| Where | 被控：Windows 10/11 PC；控制：Windows/macOS 桌面，之后 iPad/iPhone；网络：Tailscale tailnet 为主 |
| When | 个人项目，无硬期限 [假设] |
| How | Rust 被控端 Agent + Tauri 2 控制端 + QUIC 传输 + 三级渲染管线（见 03_architecture） |
| How much | 零服务器成本优先（Tailscale 免费个人版承担 NAT 穿透与中继）[假设] |

## 2. 用户故事与验收标准
| ID | 故事 | 验收标准 | 阶段 |
|---|---|---|---|
| US-01 | 作为用户，我能在控制端看到被控 PC 的窗口列表（标题、图标、进程名） | 列表 ≤ 1 s 返回；新开/关闭窗口 2 s 内刷新 | M1 |
| US-02 | 我能打开某个窗口的实时画面并用键鼠操控 | LAN 端到端延迟 P95 < 50 ms，tailnet 直连 P95 < 120 ms；30–60 fps | M1 |
| US-03 | 窗口画面按我的控制端视口 1:1 显示，字清晰 | “适配模式”下远端窗口被调整为视口尺寸，无缩放；静止 300 ms 后文字区与源像素逐像素一致（无损精修） | M1 |
| US-04 | 窗口的弹出菜单、对话框能正常显示和操作 | 同进程 owned 窗口自动出现在同一视图中 | M1 |
| US-05 | 我能在控制端开一个远端终端，用本地字体和字号显示 | 终端模式带宽空闲 < 1 Kbps、持续输出 < 50 Kbps；支持 256 色/真彩、resize、中文 IME | M1 |
| US-06 | 首次连接用一次性配对码，之后设备自动信任 | 未配对设备无法建立会话；配对码 6 位、5 分钟过期、一次有效 | M1 |
| US-07 | 我能在 iPad/iPhone 上控制 | 触摸映射为鼠标（直接点击 + 触控板两种模式）、软键盘、捏合缩放 | M2 |
| US-08 | Chrome/Edge/Electron 窗口可用“语义模式”在控制端重排显示 | 控制端按本地视口宽度重排；点击/输入回放到远端 | M3 |
| US-09 | 原生程序文字以本地渲染叠加，提高小屏可读性 | 暴露 UIA TextPattern/Name 的控件文字被覆盖渲染 | M4 |

## 3. 范围
- 范围内（MVP=M1）：Windows 被控端 Agent（用户态）、桌面控制端（Windows/macOS）、窗口捕获/编码/传输/输入、1:1 适配、无损精修、终端模式、配对与信任、Tailscale 直连。
- 非目标（MVP）：文件传输、音频、剪贴板之外的设备重定向、整屏模式、UAC/安全桌面/登录界面、无人值守服务模式、多用户/账号体系、自建中继。
- 后续：M2 移动端控制；M3 Web DOM 镜像；M4 UIA 文字层 + macOS 被控；可选：自建中继、剪贴板同步（建议 M1 末尾小任务，待用户决定）。

## 4. 假设
- [假设] 被控与控制设备都已安装并登录同一 Tailscale tailnet。
- [假设] 被控 PC 有 D3D11 能力 GPU（核显即可）；无硬编时可软编 1080p30。
- [假设] 用户有一台 Mac 用于构建/签名 iOS 版（M2 前需确认）。

## 5. 风险
| 风险 | 影响 | 对策 |
|---|---|---|
| WebView 中视频解码（WebCodecs）性能/4:4:4 支持不一 | 控制端卡顿或字糊 | 文字清晰度不依赖 4:4:4：运动用 4:2:0 H.264，静止用无损瓦片；M0 Spike 验证 |
| 调整远端窗口尺寸影响本机使用者/窗口有最小尺寸 | 体验 | 断开时恢复原尺寸；达不到时退化为锐利缩放 |
| 后台窗口无法注入输入 | 操控失败 | 操作时置前；记录不兼容程序 |
| Tauri IPC 传大帧开销 | 延迟 | 用 Tauri 2 Channel 二进制 / 自定义协议；Spike 验证 |
| iOS 构建需要 Mac 与开发者账号 | M2 阻塞 | 提前确认 |
