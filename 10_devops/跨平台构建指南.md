# 跨平台构建指南（Windows / macOS / iOS / Android）

> 对齐项目宪法 #4：`apps/rd-controller` 已通过 `cfg(windows)` 与 `cfg(not(any(target_os = "android", target_os = "ios")))` 完成全平台解耦，支持在四大平台编译运行。

## 1. 平台能力矩阵

| 平台 | 产品形态 | 依赖隔离 | 打包产物 |
|---|---|---|---|
| **Windows (x64)** | 融合版（控制端 + 内嵌 `rd-agent` 被控核心 + 托盘自启） | 启用 `rd-agent` / `winreg` / `windows` / `tauri.windows.conf.json` (`ffmpeg-bin/*`) | NSIS `.exe` + 便携 `rd-agent.zip` |
| **macOS (Apple Silicon / Intel)** | 融合版（控制端 + 内嵌 `rd-agent` 被控核心，基于 `crates/rd-mac` CoreGraphics 捕获/窗口枚举/CGEvent 注入） | 自动启用 `rd-mac`，剔除 Windows 专属 `rd-*-win` 与 `ffmpeg-bin/*`；首次被控需授「屏幕录制 + 辅助功能」权限 | `.dmg` + `.app.tar.gz` |
| **Android (ARM64 / ARMv7)** | 移动控制端（触控手势翻译 `rd-touch-translate` + 手机比例虚拟屏） | 自动剔除 `rd-agent` / `arboard` / `updater` / `tray-icon` | `.apk` / `.aab` |
| **iOS (ARM64)** | 移动控制端（同 Android） | 同 Android | `.ipa`（需 macOS + Xcode） |

## 2. 本地构建命令

### Windows
```powershell
pnpm -C apps/rd-controller install
pnpm -C apps/rd-controller tauri build
```

### macOS
```bash
pnpm -C apps/rd-controller install
pnpm -C apps/rd-controller tauri build
```

#### macOS 安装常见问题与首次权限配置
1. **提示“rd-controller 已损坏，无法打开，你应该将它移到废纸篓”**
   - 原因：未做苹果付费公证（Notarization）的应用会被 macOS 打上 `com.apple.quarantine` 隔离属性。
   - 解决：先将 `rd-controller.app` 拖入「应用程序（Applications）」，然后在终端执行：
     ```bash
     xattr -cr /Applications/rd-controller.app
     ```
     （如仍提示签名问题，可执行本机临时签名：`codesign --force --deep --sign - /Applications/rd-controller.app`）
2. **首次打开设置《隐私与安全性》（双向远控 / 被控端必需）**
   - 打开 `rd-controller` 后，软件会自动检测 macOS 权限并在顶部弹出快捷引导栏；也可手动前往 **系统设置 → 隐私与安全性**：
     - **屏幕录制**：勾选 `rd-controller`（允许捕获窗口画面）
     - **辅助功能**：勾选 `rd-controller`（允许远程键鼠注入）
   - 勾选后退出并重新打开 `rd-controller` 即可生效。

### Android（需 Android SDK + NDK + `rustup target add aarch64-linux-android`）
```bash
cd apps/rd-controller
pnpm tauri android init     # 首次初始化 gen/android 工程
pnpm tauri android build    # 产出 APK / AAB
```

### iOS（需 macOS + Xcode + `rustup target add aarch64-apple-ios`）
```bash
cd apps/rd-controller
pnpm tauri ios init         # 首次初始化 gen/apple Xcode 工程
pnpm tauri ios build        # 产出 IPA（支持免费 Apple ID 侧载）
```
