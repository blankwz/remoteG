# 构建与发布
- 状态：已确认

- 仓库：GitHub 私有仓库 [假设]；CI：GitHub Actions。
- CI 矩阵：`windows-latest`（agent + controller）、`macos-latest`（controller；M2 增加 iOS 构建）。
- 每次 PR：`cargo fmt --check`、`cargo clippy --workspace -- -D warnings`、`cargo test --workspace`、`pnpm -C apps/rd-controller lint && pnpm -C apps/rd-controller test`。
- 产物：Agent 便携 zip（单 exe），Controller 用 `tauri build`（Windows MSI / macOS dmg）。个人使用不做代码签名 [假设]，iOS 需开发者签名。
- 回滚：GitHub Releases 保留历史版本；协议带 `proto_ver`，不兼容时双方提示升级，Agent 与 Controller 需同版本发布。
- ffmpeg：动态链接 LGPL 构建（避免 GPL 组件），随 Agent 打包 DLL。
