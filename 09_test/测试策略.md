# 测试策略
- 状态：已确认

| 层级 | 内容 | 工具/命令 |
|---|---|---|
| 单元 | 协议编解码、坐标映射（含 DPI 100/125/150/200%）、瓦片编解码、配对状态机 | `cargo test --workspace` |
| 集成 | Agent ↔ 无头测试客户端（Rust）：鉴权、窗口列表、视频首帧、终端回显 | `cargo test -p rd-agent --test e2e` |
| 文字清晰度基准 | `tools/clarity-bench`：被控端打开固定文本测试窗口（多字号、ClearType、彩色字），控制端截取静止 300 ms 后的画面与源帧对比 | 指标：文字区 PSNR = ∞（逐像素一致）；运动中 SSIM ≥ 0.95 |
| 延迟基准 | 测试窗口显示毫秒时间码/色块，控制端识别后与本地时钟比较（两端 NTP 同步）或用输入→画面回环法 | 指标见 INDEX 成功指标 |
| 兼容性手测 | 记事本、VS Code、Chrome、Windows Terminal、资源管理器、Office、一款 Qt 程序；DPI 100%/150% | 清单记录于 09_test/兼容性.md（M1 建立） |
| 网络 | tailnet 直连 / DERP 中继 / 人为丢包 5%（`clumsy`） | 不崩溃、码率自适应生效 |
