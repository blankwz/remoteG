# 手测指南（小白版）

> 这份文档带你完成 rd 远程控制的完整验收（T-026）。全程约 40 分钟（不含 1 小时稳定性）。
> 测试环境 = 同一台电脑（被控端和控制端都是它）。跨机/远程项目在第 7 步，可选。

---

## 第 0 步：准备（一次性，约 2 分钟）

1. **关闭旧的 rd-agent**：如果任务栏右下角托盘有灰色/绿色图标 → 右键 →「退出」。
   （上一轮测试留下的旧版本进程，不关会互相干扰）
2. 4 个 bat 在 `C:\rd-test\` 文件夹（`C:\rd` 是指向代码仓库的目录联接，不需要管）。
3. **不需要**命令行、不需要 Node、不需要 Tailscale（同机测试全部不涉及）。

| bat | 作用 | 说明 |
|---|---|---|
| 1-启动被控端.bat | 双击启动被控端 | 启动后**没有黑窗口**（新版无控制台），看任务栏托盘图标 |
| 2-启动控制端.bat | 双击启动控制端 | 产物已预先构建好，双击秒开；若提示构建说明产物被删，等 5~15 分钟 |
| 3-启动测试窗口.bat | 打开一个专用测试窗口 | 测画面用 |
| 4-清晰度比对.bat | 截图对比工具 | 第 5 步用 |

---

## 第 1 步：启动（双击顺序 1 → 2）

1. 双击 **1-启动被控端.bat** → 窗口闪一下自动关 → **看任务栏右下角托盘**，出现灰色图标。
   右键图标应能看到菜单：生成配对码 / 已连接 / 断开所有 / 暂停共享 / **开机自启** / **信任设备** / 打开日志目录 / 退出。
   - ✅ 通过标准：托盘图标出现、菜单项齐全（有「开机自启」和「信任设备」两个新项）。
2. 双击 **2-启动控制端.bat** → rd-controller 窗口弹出，默认在「设备」页。
   - ✅ 通过标准：窗口出现，页面上有「扫描局域网」和「添加设备」两个按钮。

> 如果上轮测试已配对过（设备页有设备卡片），直接做第 2 步「连接」。
> 如果连接时报「指纹不匹配」，现在不用删设备了——会自动弹出重新配对框，跳到第 3 步第 2 小节。

---

## 第 2 步：连接（两条路都测，约 3 分钟）

### 2a. 已有设备卡（上次配对过）

1. 点设备卡片（`127.0.0.1:21118`）→ 直接连上（**已配对设备不再弹确认框**，配对即授权）。
   - ✅ 通过标准：1 秒内跳到窗口列表页，列出所有窗口（标题 + 图标）。
2. 想验证「连接确认」强模式：在被控端 `%APPDATA%\rd\data\agent.toml` 写入 `confirm_connection = true` 并重启被控端 → 再连接应弹确认框（点「是」放行）→ 测完把该行删掉恢复默认。

### 2b. 局域网扫描（新功能，模拟"帮家人"）

1. 回到「设备」页 → 点「**扫描局域网**」→ 等约 2 秒。
2. 应出现「局域网发现」区域，列出本机（主机名 + IP）。
3. 点「添加」→ 弹出添加对话框（地址已自动填好）。
4. 在被控端托盘点「生成配对码」→ 弹窗里**首行就是本机地址**（新功能：以前只有配对码）→ 输入 6 位码 → 配对。
   - ✅ 通过标准：扫描能发现设备、配对成功、设备列表出现新卡片。
5. 多余的重复设备卡可以「删除」清理掉。

## 第 3 步：新功能专项（每项 1~2 分钟）

| # | 测什么 | 怎么操作 | ✅ 通过标准 |
|---|---|---|---|
| 1 | **开机自启** | 托盘右键 → 勾「开机自启」→ 再取消勾选 | 勾选/取消无报错（重启电脑后托盘图标自动出现算完整验证，可选） |
| 2 | **只看不控** | 进入一个窗口会话 → 勾选左上角工具条「只看不控」（画面会刷新一下）→ 在画面上点击、打字 | 远端窗口**完全没反应**；取消勾选后恢复可控 |
| 3 | **本机优先**（向日葵式） | 会话开着，在**被控端本机**动一下鼠标/键盘 → 立刻在控制端画面点击 | 被控端本机操作的 2 秒内，控制端画面**点击无效** + 光标变 🚫 + 顶部横幅「对方正在使用电脑」；停手约 2 秒后自动恢复可控。**这就是"对方在用时不抢鼠标"** |
| 4 | **复制到远端** | 在控制端（本机）复制一段文字 → 会话页点「复制到远端」 | 按钮无报错。同机回环剪贴板是同一个，真实效果需跨机（远端 Ctrl+V 出现文字） |
| 5 | **从远端复制** | 会话页点「从远端复制」 | 无报错（同机回环同上） |
| 6 | **暂停共享杀终端** | 会话里点「终端」开一个终端（确认能输出 ls）→ **被控端**托盘勾「暂停共享」 | 控制端终端**立刻断开**（输入无响应/流关闭）；被控端任务管理器里 powershell/cmd 子进程**消失**；取消暂停后控制端顶部有恢复提示、重新开终端正常 |
| 7 | **锁屏横幅** | 同机无法测（锁屏后自己也看不见）→ **跳过**，跨机时测：对方锁屏后控制端顶部应出现黄色横幅「对方已锁屏」 | 跨机场景项 |
| 8 | **撤销信任** | 被控端托盘 →「信任设备」→ 看到设备条目 → 点它 | 控制端被立刻断开；设备页变「未连接」；再连接需要重新配对（测完按 2b 重新配对回来） |
| 9 | **鼠标流畅度** | 在画面上快速大范围画圈移动鼠标 10 秒 | 远端窗口内的悬停/拖拽跟随应**平滑无明显顿挫**（本轮注入已从 60Hz 提到 125Hz；画面本身上限 60fps） |

## 第 4 步：逐项兼容性测试（每测一个应用重复一轮）

被控机上打开一个应用 → 控制端窗口列表自动出现 → **点它进入画面** → 按下表测：

| 测什么 | 怎么操作 | 通过标准 |
|---|---|---|
| 画面 | 看会话页 | 能看到远端窗口内容，动远端鼠标画面跟着变 |
| Fit 1:1 | 拖动控制端窗口大小 | 远端窗口跟着变，**画面文字不模糊** |
| 鼠标点击 | 在画面上点按钮/菜单 | 点哪是哪（误差 ≤1 像素） |
| 键盘 | 点画面后打字 | 字出现在远端窗口 |
| 中文/IME | 切中文输入法打"你好" | 上屏正常 |
| 滚轮 | 在画面上滚 | 远端跟着滚 |
| 弹出菜单 | 远端窗口右键 | 菜单能点（菜单本体可能不可见，已知限制） |
| **最小化窗口** | 把远端窗口最小化 → 控制端窗口列表点它 | 自动还原并可控制；会话关闭后窗口**回到最小化**（新修复） |
| **窗口销毁** | 会话开着时直接关闭远端窗口 | 控制端标签自动收场，无冻结黑帧 |
| **断线重连** | 被控端托盘「退出」rd-agent → 控制端观察 | 出现「被控端已退出」类提示（不再是干等）；重开 agent 后自动恢复重连 |

## 第 5 步：清晰度比对（US-03 核心验收，约 3 分钟）

同上一轮：打开 testwin（bat 3）→ 会话里等静止 5 秒 → bat 4 截图比对。
- ✅ 通过标准：文字区与源像素逐像素一致（exact=1.0），或肉眼看时间码/小字号清晰无涂抹。

## 第 6 步：延迟与稳定性

- **延迟**：HUD 看 RTT（同机应 <10ms）；精确测量同上一轮手机拍屏法。
- **1 小时稳定性**：开着会话挂 1 小时（含终端 + 一个应用窗口），期间正常使用电脑：
  - ✅ 通过标准：画面不冻、无内存爆炸（任务管理器看 rd-agent <500MB）、终端仍可用。
  - **注意**：新版被控端在会话期间会**阻止屏保/睡眠**——挂机测试时屏幕不会自己黑掉，这是特性不是 bug。

## 第 7 步：跨机远程测试（需要第二台电脑）

### 7.0 准备（10 分钟）

**两个安装产物**（都在开发机）：

| 文件 | 位置 | 装到哪台 |
|---|---|---|
| `rd-controller_0.1.0_x64-setup.exe`（2.8MB，控制端安装包） | `apps\rd-controller\src-tauri\target\release\bundle\nsis\` | **控制机**（你手里操作的那台） |
| `rd-agent-0.1.0-win64.zip`（69MB，被控端便携包） | `dist\` | **被控机**（被远程的那台） |

被控端 zip 传输后核对校验和（防损坏）：`SHA256 = EDBE7073F6CACE3D29E3992463695C7610185CA17A8BB248E245F0678F54831F`（同目录 `.sha256` 文件同值）。

布置建议：**现在这台开发机当被控机**（rd-agent 已就绪），第二台装控制端；或反过来，两边文件都拷。

### 7A. 同一 WiFi 直连（推荐先测，零依赖，约 5 分钟）

1. 两台电脑连**同一个 WiFi/路由器**
2. 被控机解压 zip → **双击 `rd-agent.exe`**（无黑窗，看托盘图标；Windows 防火墙首次弹窗点「允许」）
3. 被控端托盘「生成配对码」→ 弹窗**首行就是被控机地址**（192.168.x.x:21118）
4. 控制机「设备」页 →「**扫描局域网**」→ 应列出被控机 →「添加」→ 输 6 位配对码
5. 点设备卡片连接

### 7B. 跨网络（Tailscale，模拟"帮外地家人"）

1. 两台电脑都装 [Tailscale](https://tailscale.com/download)
2. 你（控制机）登录自己的账号；被控机用你在 Tailscale 管理页发的**邀请链接**加入（节点共享，对方用自己的账号，无需登你的）
3. 被控端无需任何配置（自动监听 Tailscale 网段）；控制端地址填被控机 Tailscale IP（`100.x.y.z`，托盘配对弹窗首行有）
4. 配对同 7A

### 7C. 跨机测试矩阵（按序测，✅/❌ 记录）

| # | 项目 | 操作 | ✅ 通过标准 |
|---|---|---|---|
| 1 | 首连配对 | 全新设备走完 7A 全程 | 电话可指导完成（小白标准） |
| 2 | 画面+延迟 | 开 testwin 会话，看 HUD | 画面流畅；**同 WiFi RTT 应 <15ms**、Tailscale 直连 <50ms、走 DERP 中继 <120ms |
| 3 | 鼠标流畅度 | 大范围移动/拖拽 10 秒 | 120fps 采样，无明显顿挫/发糊 |
| 4 | 清晰度 | 静止 5 秒后 Ctrl+Shift+S 截图比对（或肉眼看小字） | 文字清晰无涂抹 |
| 5 | **本机优先** | 被控人本机动鼠标，同时控制端点击 | 控制端 🚫 + 横幅，被控人停手 2 秒自动恢复 |
| 6 | **锁屏横幅** | 对方按 Win+L 锁屏 | 控制端横幅「对方已锁屏」；解锁后画面自动恢复 |
| 7 | **剪贴板互传** | 控制端复制文字→「复制到远端」→被控机 Ctrl+V；反向「从远端复制」 | 文字真实出现 |
| 8 | 断网 30 秒 | 被控机关 WiFi 再开 | 恢复后**自动重连**（不需要人点重试） |
| 9 | 对方重启 | 重启被控机（已勾开机自启） | 开机后托盘自动出现 → 控制端自动恢复连接 |
| 10 | 1 小时稳定性 | 挂会话正常使用 1 小时 | 不冻结/不崩溃/终端可用 |

## 常见问题（遇到先看这里）

| 现象 | 原因与处理 |
|---|---|
| 双击 bat 1 没有黑窗口，不知道启动没 | **正常**（新版无控制台）。看任务栏托盘图标 |
| 控制端连接时被控端弹"允许吗" | 2026-10-23 已改为**默认不弹**（配对即授权）。想要强确认的可在被控端 `agent.toml` 加 `confirm_connection = true`；注意该弹窗受 Windows 前台锁限制只闪任务栏不前置（已知限制） |
| 点设备卡片报"指纹不匹配" | 现在会**自动弹出重新配对框**——对方托盘「生成配对码」，输入新码即可 |
| 扫描局域网扫不到 | 确认被控端 bat 1 已启动（托盘有图标）；防火墙首次可能弹窗，点「允许」 |
| 会话画面冻住不动 | 先看是否勾了「只看不控」/托盘勾了「暂停共享」；再想对方是否锁屏（解锁自动恢复）；最后按断线重连处理 |
| 弹出菜单本体看不到 | Windows 硬限制（WGC 不能捕获菜单窗口），菜单**可以点击**，已知限制 |
| Alt+Tab / Win 键没反应 | WebView2 拦截，已知限制 |
| 管理员窗口打字无效 | 现在会弹提示「对方窗口以管理员权限运行…」（新功能）；需对方以管理员运行 rd-agent |
| bat 2 提示要构建 5~15 分钟 | release 产物被删了，等它跑完（以后秒开）；或找 Orchestrator 重新构建 |
