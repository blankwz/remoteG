# 兼容性手测指南（T-026）

> 本文档是**手把手操作指南**：从启动两个程序到逐项打勾。全程约 30 分钟（稳定性 1 小时另计）。

---

## 一、准备：启动两个程序

需要两个终端窗口（在仓库根 `G:\AICODE\0claude\REQ-20261013-001-窗口级远程控制` 下执行）。

### 1. 启动被控端 Agent（方式 A：打包产物，推荐）

```bash
powershell -Command "Expand-Archive dist/rd-agent-0.1.0-win64.zip dist\agent-run -Force; Start-Process dist\agent-run\rd-agent.exe -ArgumentList 'run','--listen','127.0.0.1:21118'"
```

- 启动后**任务栏右下角出现托盘图标**（灰色方块），即 Agent 就绪。
- 推荐方式 A 的原因：zip 自带全部 DLL，双击即用，不依赖开发环境。

### 1'. 启动被控端 Agent（方式 B：开发构建）

```bash
cargo run -p rd-agent -- run --listen 127.0.0.1:21118
```

- 若报缺少 `avcodec-63.dll` 等错误：把 `C:\Users\blank\rd-dev\ffmpeg-n9.0-latest-win64-lgpl-shared-9.0\bin\*.dll` 复制到 `target\release\` 后重试。

### 2. 启动控制端（另一个终端）

```bash
pnpm -C apps/rd-controller tauri dev
```

- 首次编译约 3 分钟；之后弹出 **rd-controller 窗口**，进入设备页（`#/devices`）。

### 3. 配对（首次一次即可，之后免码）

1. 点**托盘图标**右键 →「生成配对码」→ 弹窗显示 6 位数字（5 分钟有效）。
2. 控制端设备页 →「添加设备」→ 地址填 `127.0.0.1:21118`（或 Tailscale IP `100.81.205.0:21118`）、粘贴 6 位码 → 确认。
3. **期望**：设备卡片出现（名称/地址/指纹），Agent 日志显示"受信任设备接入"。之后重启双方无需再配对。

### 4. 进入被控窗口

1. 在被控机上**随便打开一个应用**（如记事本）。
2. 控制端**点击设备卡片** → 自动跳转 `#/windows/...` 窗口列表页。
3. **期望**：1 秒内列出所有可捕获窗口（含刚打开的记事本，带图标）。
4. **点击窗口卡片** → 进入会话页：画面出现、HUD 显示 fps/RTT/码率。

> 以下每项测试都按这个路径：**被控机开应用 → 列表点开 → 会话页操作**。测试完点标签上的 × 关闭。

## 三、专项测试

### 1. 文字清晰度（US-03 核心验收，5 分钟）

**原理**：比对"源窗口像素"与"控制端显示像素"是否逐位一致。

```bash
# ① 被控机起一个标准测试窗口（含各字号文字+四角品红定位标）
cargo run -p clarity-bench -- testwin --mode static --size 1280x800
```

```bash
# ② 被控机截全屏作为"源图"（PowerShell）
powershell -Command "Add-Type -AssemblyName System.Windows.Forms,System.Drawing; $b=[System.Windows.Forms.Screen]::PrimaryScreen.Bounds; $bmp=New-Object System.Drawing.Bitmap $b.Width,$b.Height; $g=[System.Drawing.Graphics]::FromImage($bmp); $g.CopyFromScreen(0,0,0,0,$b.Size); $bmp.Save('G:\AICODE\0claude\REQ-20261013-001-窗口级远程控制\dist\source.png')"
```

3. 控制端窗口列表里打开 **clarity-bench** 窗口 → 等 **1 秒**（瓦片精修完成）→ 按 `Ctrl+Shift+S` 导出画面 PNG（存到下载目录，文件名 `rd-<id>-<时间戳>.png`）。

```bash
# ③ 比对（把第一个路径换成你下载目录里的实际文件）
cargo run -p clarity-bench -- compare "C:\Users\blank\Downloads\rd-xxxx.png" "dist\source.png" --json
```

**通过标准**：`"text_exact_ratio": 1.0` 且 `"aligned": true`（PSNR 为 null 表示零误差，正常）。

> 原理：compare 会在两张图里自动找品红角标对齐并裁剪，所以截全屏没关系。

### 2. 端到端延迟（US-02，5 分钟/场景）

**原理**：测试窗口右上角有毫秒级时间码，控制端画面里也有同一时间码。手机把两处拍进同一张照片，两个数字之差 = 端到端延迟。

```bash
# 被控机起时钟窗口
cargo run -p clarity-bench -- testwin --mode clock --size 1280x800
```

1. 控制端打开该窗口会话，**把控制端窗口和源窗口摆到同一屏幕相邻位置**（场景 A 同机）。
2. 手机**快门 1/125s 以上**拍一张清晰照片。
3. 放大照片读两个时间码，**差值 = 延迟**。拍 5 张取平均与最大值。
4. 场景 C：`tailscale status` 看被控↔控制端那行是直连还是 `relay "xxx"`，各测一次记录。
5. **通过标准**：同机 P95 < 50ms；tailnet 直连 P95 < 120ms；DERP 记录数值。

### 3. 1 小时稳定性

1. 被控机开 VS Code + 一个控制端终端标签（会话页「+ 终端」→ pwsh）。
2. 正常使用 1 小时（编码/敲命令）。
3. **通过标准**：两端无崩溃；任务管理器看 rd-agent.exe / rd-controller.exe 内存无持续增长（首 10 分钟的缓存增长属正常）。

### 4. 终端专项（US-05）

会话页「+ 终端」→ pwsh：`ls`、中文输出、`Ctrl+=`/`Ctrl+-` 调字号；`?term=wsl` 直开 WSL 试 `vim`（`:q` 退出）全屏渲染；关掉控制端网络 30 秒再恢复 → 终端标签自动 resume，**期间输出可见**。

## 五、已知限制（测试时不必报障）

1. **弹出菜单无画面**（Windows 硬限制，WGC 不能捕获 #32768 窗口）：右键菜单时能看到"菜单事件"但菜单本体不在画面里，点击菜单项仍生效。
2. Alt+Tab、Win 键组合被 WebView2 拦截，无法透传。
3. Ctrl+Alt+Del 无法注入。
4. 管理员权限运行的窗口无法注入（UIPI），会报错而非静默失败。
5. UWP 窗口（如计算器）进程名显示为 ApplicationFrameHost 相关，属正常。
6. 本机 NVIDIA 驱动 <610.00：硬编走 h264_mf，4:4:4 不可用（升级驱动自动启用）。
