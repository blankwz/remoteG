# 手测指南（小白版）

> 全程只做三件事：**双击 bat 文件 → 鼠标点击 → 看现象**。不需要打开任何命令行。
> 预计用时 30 分钟（稳定性测试 1 小时另计）。

---

## 第 0 步：认识 4 个 bat 文件（在 `C:\rd-test\` 文件夹里）

| 文件名 | 双击后会发生什么 |
|---|---|
| `1-启动被控端.bat` | 后台启动"被控端"（rd-agent），**屏幕右下角托盘出现图标** = 成功 |
| `2-启动控制端.bat` | 弹出"rd-controller"控制端窗口（首次编译约 1~3 分钟，黑窗口**不要关**） |
| `3-启动测试窗口.bat` | 弹出一个测试窗口（右上角有跳动的毫秒时间码，用来测延迟/清晰度） |
| `4-清晰度比对.bat` | 自动比对"源画面"和"控制端画面"是否逐像素一致，直接给出分数 |

> 所有 bat 都在 `C:\rd-test\`。如果这个文件夹没了，告诉我重建。

### 为什么在 C 盘？（背景说明，不需要操作）

仓库路径含中文，cmd 批处理对中文路径有多层兼容坑（实测：编码 BOM、路径截断、跳行）。所以：

- **`C:\rd`** 是一个"目录联接"（快捷方式级别的别名），指向中文仓库目录——通过它访问的就是同一份代码，不是复制
- bat 文件放 `C:\rd-test\`，内部全部用 `C:\rd\...` 纯英文路径

**如果要在命令行手动操作**（一般用不到，双击 bat 即可）：必须先进 `C:\rd\apps\rd-controller` 目录再执行 pnpm 命令，例如：

```bat
cd /d C:\rd\apps\rd-controller
pnpm tauri dev
```

直接在 `C:\rd` 根目录执行 `pnpm tauri dev` 会报 `No package.json`（package.json 在 apps\rd-controller 子目录里）。

## 第 1 步：启动（双击顺序 1 → 2）

1. 双击 **`1-启动被控端.bat`** → 看到"[成功] Agent 已运行"后，按任意键关掉黑窗口（Agent 还在后台跑）
2. 双击 **`2-启动控制端.bat`** → 等黑窗口编译完，**rd-controller 窗口**弹出来
3. 双击 **`3-启动测试窗口.bat`** → 弹出时钟测试窗口（测延迟/清晰度用，测其他应用时可关掉）

**如果托盘没有图标 / 控制端弹窗报错**：截图发我，不要自己折腾。

---

## 第 2 步：连接被控端（已配对过，点一下就行）

1. 控制端窗口默认在 **「设备」页**，能看到一张设备卡片（`127.0.0.1:21118`，指纹 `bba5cf26...`）
2. **点这张卡片** → 自动跳到「窗口列表」页
3. **通过标准**：1 秒内列出电脑上所有窗口（标题 + 图标）

> 如果显示"设备未连接"：点「重试」（新版会自动重新连设备）。还是不行 → 截图发我。

## 第 3 步：逐项测试（每测一个应用，重复一遍这个流程）

被控机上打开一个应用（如记事本）→ 控制端窗口列表会自动出现它 → **点它进入画面** → 按下表测：

| 测什么 | 怎么操作 | 通过标准 |
|---|---|---|
| 画面 | 看会话页 | 能看到远端窗口内容，动一下远端鼠标画面跟着变 |
| Fit 1:1 | 拖动控制端窗口大小 | 远端窗口跟着变，**画面文字不模糊** |
| 鼠标点击 | 在画面上点按钮/菜单 | 点哪是哪（误差不超过 1 个像素） |
| 键盘 | 点一下画面后打字 | 字出现在远端窗口 |
| 中文/IME | 切中文输入法打"你好" | 上屏正常 |
| 滚轮 | 在画面上滚 | 远端跟着滚 |
| 弹出菜单 | 远端窗口上右键 | 菜单弹出（注意：菜单本体可能不可见，见已知限制 1），点菜单项能生效 |

## 第 4 步：清晰度比对（US-03 核心验收，约 3 分钟）

1. 双击 **`3-启动测试窗口.bat`**（保持弹出的时钟窗口**不被遮挡**）
2. 控制端窗口列表 → 点开 **clarity-bench** → 会话页显示测试窗口画面
3. **静止 1 秒**（不要动鼠标），按 **`Ctrl+Shift+S`** → 控制端画面已导出到你的**下载文件夹**（文件名 `rd-开头.png`）
4. 双击 **`4-清晰度比对.bat`** → 自动截屏 + 比对 → 输出 JSON

**看这个字段**：`"text_exact_ratio": 1.0` = 满分（文字逐像素一致）。小于 1 记录数值发我。

> 原理：脚本自动截你的屏幕当"源图"，和导出图自动对齐比对，不需要手动截图。

---

## 第 5 步：延迟测量（US-02，约 5 分钟）

1. 保持时钟测试窗口 + 控制端会话页**同时显示在同一块屏幕上**（并排摆放）
2. 两处都有**毫秒时间码**（09:xx:xx.xxx）
3. 用**手机拍照**（快门快一点，拍 5 张）
4. 放大照片，读出「源窗口时间码」和「控制端画面时间码」，**相减 = 延迟**
5. 5 张取平均

**通过标准**：平均 < 50ms 就是优秀（同机回环通常只有 5~20ms）。

> 局域网另一台电脑测试（场景 B）：第二台电脑装 Tailscale 登同一账号，跑控制端后地址填被控机的 Tailscale IP（`100.81.205.0:21118`），方法相同。

2. 正常操作 1 小时

## 常见问题（遇到先看这里）

| 现象 | 原因与处理 |
|---|---|
| 点设备卡片报"指纹不匹配" | Agent 换了证书（重装/重打包）。现在点连接时会**自动弹出重新配对框**——让对方在托盘点「生成配对码」，输入新配对码即可，不用删设备了 |
| 弹出菜单本体看不到 | Windows 硬限制（WGC 不能捕获菜单窗口），菜单**可以点击**，属已知限制 |
| Alt+Tab / Win 键没反应 | WebView2 拦截，已知限制 |
| 管理员窗口打字无效 | 权限限制（UIPI），已知限制 |
| **对方电脑锁屏/UAC 弹窗时画面不动** | 属预期行为（Windows 安全桌面），解锁后自动恢复；期间终端不受影响 |
| 窗口列表里没有某应用 | 该应用可能最小化了——**先最小化的窗口现在会自动还原**，若还不出现截图发我 |
| 控制端黑屏但鼠标能动 | 截图 + F12 Console 报错发我 |

## 没装 Tailscale？同一 WiFi 直连（帮家人最常用）

被控端 Agent 启动后**自动监听局域网地址**（192.168.x.x），无需任何配置：

1. 两台电脑连**同一个 WiFi/路由器**
2. 控制端「设备」页点**「扫描局域网」**→ 等约 2 秒，会列出发现的被控电脑
3. 点发现的设备 → 「添加」→ 让对方在托盘点「生成配对码」→ 输入配对码 → 完成

跨网络（不同 WiFi/异地）才需要 Tailscale：对方装 Tailscale 后用你发的**邀请链接**加入（见设备页底部说明），地址填 `100.x.y.z`。
