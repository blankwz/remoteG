## 一、Phase 1 单机功能（13 项，约 30 分钟）

### 1.1 被控端在跑
- **操作**：看右下角托盘，灰色 rd 图标 → 右键点它
- **应看到**：菜单里有「生成配对码 / 已连接：0 / 暂停共享 / 开机自启 / 信任设备 / 打开日志目录 / 授权… / 退出」
- **出问题贴什么**：托盘截图

### 1.2 控制端连上被控端
- **操作**：控制端窗口 → 点「添加设备」→ 地址填托盘「生成配对码」弹窗里显示的地址（形如 `192.168.x.x:21118`）→ 配对码填弹窗里的 6 位数字 → 确认
- **应看到**：设备卡片出现且显示在线（也可以点「扫描局域网」自动发现，更省事）
- **出问题贴什么**：控制端截图 + 托盘弹窗截图

### 1.3 打开测试窗口
- **操作**：在程序文件夹的地址栏输入 `cmd` 回车 → 在黑窗口里输入：
  ```
  clarity-bench.exe testwin --mode clock
  ```
- **应看到**：出现一个 800×600 的测试窗口（带时钟和彩色图案），标题含 clarity-bench
- **出问题贴什么**：黑窗口里的报错文字

### 1.4 看到远程画面
- **操作**：控制端 → 点设备卡片 → 出现「窗口列表」→ 点 clarity-bench 窗口打开
- **应看到**：1~3 秒内出现远程画面，时钟在走，图案清晰无花屏
- **出问题贴什么**：控制端截图 + `%LOCALAPPDATA%\rd\logs` 文件夹里最新日志的最后 20 行

### 1.5 静止区域精修（瓦片）
- **操作**：画面不动 5 秒，然后快速晃动鼠标
- **应看到**：静止的文字/图案在晃动后变得更清晰（高清瓦片叠加），全程无闪黑
- **出问题贴什么**：前后两张截图对比

### 1.6 鼠标点击
- **操作**：在远程画面里点击测试窗口的标题栏或空白处（会计入点击次数）
- **应看到**：远程窗口标题的点击计数增加
- **出问题贴什么**：点击前后的标题栏截图

### 1.7 键盘输入
- **操作**：点远程画面的标题栏获得焦点 → 打几个字 → 右键测试窗口菜单看有无响应
- **应看到**：远程窗口对键盘有反应（标题/菜单变化）
- **出问题贴什么**：描述现象 + 最新日志尾部

### 1.8 终端
- **操作**：控制端会话页 → 点顶部「+ 终端」
- **应看到**：出现一个能用的命令行，输入 `echo hello` 回车能出 `hello`
- **出问题贴什么**：终端页截图

### 1.9 剪贴板
- **操作**：在本机复制一段文字（Ctrl+C）→ 会话画面**下方**找到会话工具条，点「把控制端剪贴板文本发送到远端」→ 在远程终端里按 Ctrl+V
- **应看到**：粘贴出的是刚才复制的文字；反向点「取回远端剪贴板文本到控制端」也能拿到
- **出问题贴什么**：描述哪一步没生效

### 1.10 工具栏四件套（画质/常用语/虚拟按键/截屏）
- **操作**：远程画面顶部找到悬浮工具栏：
  - 画质选「流畅」→ 画面略微变糊但很顺；选「高清」→ 变清晰
  - 点 📋 常用语 → 点「你好」→ 远程应出现这两个字
  - 点 ⌨ 虚拟按键 → 点 Enter → 远程有回车效果
  - 点 📸 截屏 → 「下载」文件夹出现一张 PNG
- **应看到**：以上全部生效，每次操作有提示气泡
- **出问题贴什么**：哪一步没反应的截图

### 1.11 隐私屏（要先放授权，见下方「准备工作」）
- **操作**：工具栏点 ⬛ → 被控端弹提示框点「确定」
- **应看到**：被控端屏幕变黑（有提示后），控制端画面照常能看能操作；再点 ⬛ 恢复；**关掉控制端窗口后黑屏自动消失**
- **出问题贴什么**：`%LOCALAPPDATA%\rd\logs\audit.jsonl` 尾部 5 行
- **准备工作**（一次性，给被控端发一个专业版授权）：打开 cmd，**先回到项目根目录**再执行（在程序文件夹里跑会找不到命令）：
  ```
  cd /d G:\AICODE\202610_control_new\REQ-20261013-001
  cargo run -p rd-security --example issue_license -- --name 测试 --plan pro --devices 99
  ```
  把输出的 `RD1.xxxx...` 整串保存为文件 `%LOCALAPPDATA%\rd\license.key`（用记事本另存），重启 rd-agent.exe（托盘右键退出再双击）。验证：托盘右键 →「授权…」应显示「专业版(Pro)」

### 1.12 录屏
- **操作**：工具栏点 ⏺ → 操作几下画面 → 再点 ⏺
- **应看到**：提示「录制已保存」，下载文件夹出现 .webm 视频且能播放
- **出问题贴什么**：提示气泡截图

### 1.13 Studio 数据面板
- **操作**：双击运行 `G:\AICODE\202610_control_new\REQ-20261013-001\switchboard\sdk\rust\target\release\switchboard-daemon.exe`（若无此文件，在 `switchboard\sdk\rust` 打开 cmd 输入 `cargo run -p switchboard-daemon --release`）→ 浏览器打开 `http://127.0.0.1:7500`
- **应看到**：「方案测试」页四张卡片，点「全部测」约 1 分钟后 4 个分数出现
- **出问题贴什么**：浏览器页面截图

## 二、Phase 2 局域网双机（11 项，约 2 小时）

**前置**：第二台 Windows 电脑（家人/笔记本均可），与第一台连**同一个 WiFi/路由器**。把 `rd-agent-0.1.0-win64.zip` 解压到第二台电脑，双击 `rd-agent.exe`（防火墙照 0.3 允许）。

| # | 测什么 | 操作 | 应看到 |
|---|---|---|---|
| 2.1 | 自动发现 | 控制端设备页点「扫描局域网」 | 列表出现第二台电脑的名字 |
| 2.2 | 连接延迟 | 连接第二台 → 会话页 HUD（Ctrl+Shift+H）看 RTT | RTT < 15ms（同 WiFi） |
| 2.3 | 文字清晰度 | 远程打开一个文档/网页 | 文字清晰可读 |
| 2.4 | 视频流畅度 | 远程播放一个视频窗口（testwin --mode scroll 也行） | 流畅不卡顿 |
| 2.5 | 鼠标跟手 | 快速画圈 | 光标无明显滞后 |
| 2.6 | 断线重连 | 拔掉第二台电脑的网线/关 WiFi 5 秒再恢复 | 控制端自动重连成功（画面恢复） |
| 2.7 | 码率自适应 | 远程开一个大窗口观察 HUD 的 kbps | 数字自动升降、画面不卡死 |
| 2.8 | 多窗口 | 同时开 2 个远程窗口标签 | 两个画面都正常 |
| 2.9 | 长时间稳定 | 连续使用 30 分钟 | 不崩溃、不明显变慢 |
| 2.10 | fec 高清链路 | 控制端：先关闭 rd-controller，然后在 cmd 里用命令启动（见下）→ 重新连第二台 → 开窗口 | 画面正常（此时走 fec 分片通道） |
| 2.11 | fec 回退 | 不设环境变量直接启动控制端再连 | 画面正常（回到可靠流通道） |

**2.10 的启动命令**（cmd 里，一行）：
```
set RD_MEDIA_FEC=1 && rd-controller.exe
```

**每项出问题都贴**：第二台电脑 `%LOCALAPPDATA%\rd\logs` 里最新日志的最后 20 行 + 控制端截图。

## 三、出问题时的日志速查

| 位置 | 里面是什么 |
|---|---|
| 被控端 `%LOCALAPPDATA%\rd\logs\rd-agent.日期.log` | 被控端全部运行记录（最重要） |
| 被控端 `%LOCALAPPDATA%\rd\logs\audit.jsonl` | 操作审计（谁连过、开了什么窗口） |
| 托盘右键 →「打开日志目录」 | 直接打开上面文件夹 |

**发给我时**：日志最后 20 行 + 一句话说明「我做了什么、期望什么、实际看到什么」。
