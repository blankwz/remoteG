# 发码 SOP（T-041）

> 量 <100/月 不做全自动（路线图既定）。全程半自动：一个脚本完成「签发→自验→台账→回邮草稿」，人工只做核对与发送。

## 日常发单（3 步）

1. **收到订单**（面包多/爱发电后台，含订单号/邮箱/套餐）。
2. **跑脚本**（PowerShell，仓库根目录）：

   ```powershell
   .\scripts\license-ledger.ps1 -Order "订单号" -Email "买家邮箱" -Name "署名（可省）" -ExpiresDays 365
   ```

   - 永久码：省略 `-ExpiresDays`。
   - 免费码（极少用）：`-Plan free -Devices 2`。
   - 脚本会：读正式种子（`RD_LICENSE_SEED` 环境变量，或默认
     `%USERPROFILE%\.rd-secrets\license-seed.txt`）→ 签发 → **签发即自验**（种子与
     内嵌公钥不配对当场报错）→ 台账追加一行 → 授权码进剪贴板 → 打印回邮草稿。
3. **核对并回邮件**：草稿贴进邮件，核对订单号/邮箱一致后发送。

台账（含授权码与买家邮箱）默认在 `%USERPROFILE%\.rd-secrets\licenses.csv`，
**敏感业务数据，不进仓库、不进聊天工具**。

## 验证一单码是否有效（买家中招排查）

```powershell
# 在被控电脑上：把码存为 %LOCALAPPDATA%\rd\license.key 后重启 rd；
# 托盘「授权…」会显示当前档位。若显示免费版：
#   1) 确认 license.key 文件名/路径正确（UTF-8 纯文本，无多余空行）
#   2) 确认买的是新版（0.3.0 起内嵌正式公钥；旧开发码在新版一律失效）
```

## 撤销/泄露预案（诚实版）

当前设计**没有单码撤销**（离线验签的代价）：授权码一旦签发，在其有效期内
始终可用。泄露应对按严重度分档：

| 场景 | 动作 |
|---|---|
| 单个码泄露、量小 | 记台账备注；效果上等价于「多几个人白用 Pro」——不轮换密钥（成本 > 收益） |
| 大面积泄露/种子疑似泄露 | **轮换种子**：`openssl rand -hex 32` 出新种子 → `show_pubkey` 派生新公钥 → 替换 `LICENSE_PUBKEY_HEX` → 发新版本；旧码随旧版失效。已付费用户凭台账重发新码（台账是唯一凭据，务必备份） |
| 台账丢失 | 无法重发凭据；恢复手段=支付平台订单记录 + 逐单重签 |

## 上线前检查

- [ ] 正式种子已从 `.rd-secrets` 转入密码管理器，本地临时文件已删
- [ ] 台账 CSV 有备份（密码管理器附件或加密盘）
- [ ] 商品文案与定价核对（¥98/年、¥198 买断；对应 `-ExpiresDays 365` 与永久）
