# 安全方案
- 状态：已确认

| 威胁 | 对策 | 验收 |
|---|---|---|
| tailnet 内其他设备/被入侵节点连接 Agent | TLS 双向 + 证书指纹信任列表；未信任只能配对 | 未配对客户端连接只收到错误码 1 |
| 配对码暴力破解 | SPAKE2（离线不可猜）；5 次失败锁定 10 分钟；码 5 分钟过期、一次有效 | 自动化测试覆盖 |
| 暴露到公网 | 默认只绑定 Tailscale 接口 IP（检测 `100.64.0.0/10`），可配置放开局域网 | 启动日志打印监听地址 |
| 信任列表/私钥泄露 | 私钥用 Windows DPAPI（`CryptProtectData`）加密存储于 `%LOCALAPPDATA%\rd\` | — |
| 本机用户不知道被控 | 托盘状态 + 窗口高亮边框 | — |
| 敏感日志 | 不记录键盘内容与终端数据 | 代码审查检查项 |
| 终端 = 完全命令执行 | 终端功能单独开关（默认开，个人使用），信任设备才可开 | — |
| M3 CDP 端口 | 仅 127.0.0.1，经 Agent 代理并鉴权 | M3 再细化 |
