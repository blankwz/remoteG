## 目标
Tauri 2 控制端可连接到指定地址，接收视频流，经 WebCodecs 解码画到 canvas，并显示 HUD（fps / 解码耗时 / 端到端延迟估计）；建立后续任务的全部文件骨架。

## 实现步骤
1. `pnpm create tauri-app`（React + TS 模板）生成到 `apps/rd-controller`，删除示例代码；`src-tauri/Cargo.toml` 独立 workspace（`[workspace]` 空表），path 依赖 `rd-transport`、`rd-proto`。
2. `conn.rs`：`ConnManager`（`tauri::State`），`HashMap<String /*device id*/, Arc<Conn>>`；M0 期间 identity 每次启动临时生成。
3. `commands/spike.rs`：`spike_connect(addr: String, on_frame: Channel<InvokeResponseBody>) -> Result<(), String>`：连接 → `accept_data` 循环 → 把视频帧（帧头+AU 原样）用 `InvokeResponseBody::Raw` 发给前端。
4. `lib.rs`：注册全部命令（含其他 feature 的桩，桩返回 `Err("not implemented")`）；同时注册 `tauri-plugin-fs`、`tauri-plugin-dialog`（T-021 截图导出用）并在 capabilities 中授权下载目录写入。桩命令清单以各任务卡“接口/命令”小节为准：devices（list_devices, pair_device, remove_device, connect_device, disconnect_device, probe_device, set_decode_caps）、windows（list_windows, subscribe_window_events）、session（open_window, close_window, set_viewport, subscribe_group_events）、input（mouse_move, mouse_button, mouse_wheel, key_event, text_input）、term（open_terminal, term_input, term_resize）。
5. `video/decoder.ts`：`H264Decoder` 封装 `VideoDecoder`，`configure({ codec: 'avc1.42E033', optimizeForLatency: true, hardwareAcceleration: 'prefer-hardware' })`（不传 description，使用 Annex-B）；第一帧必须是 keyframe，否则丢弃并请求 IDR（M0 先只记日志）；输出 `VideoFrame` 用 `ctx.drawImage` 画到 canvas 后 `frame.close()`。
6. `video/VideoCanvas.tsx`：canvas 尺寸 = 视频像素尺寸，CSS 尺寸 = 像素 / `devicePixelRatio`（保证 1:1）；`image-rendering: pixelated` 仅在非整数缩放时关闭。
7. `hud/Hud.tsx`：fps、解码耗时（decode 输出时间 − 输入时间）、`pts` 与本地时钟差（需两端时钟同步，仅作参考）。
8. `App.tsx`：路由 `/spike`（地址输入框 + 连接按钮 + VideoCanvas + Hud），其余路由放占位页。
