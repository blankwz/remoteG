## 目标
`rd-window-win` 能列出可捕获的顶层窗口（含图标）、推送窗口创建/销毁/移动/标题变化事件，并求出某根窗口的“窗口组”（弹出菜单、对话框）。

## 实现步骤
1. `enumerate.rs`：`EnumWindows` 过滤：`IsWindowVisible`、非 `WS_EX_TOOLWINDOW`（除非有 `WS_EX_APPWINDOW`）、`DwmGetWindowAttribute(DWMWA_CLOAKED) == 0`、标题非空、尺寸 > 0、排除自身进程与 `Progman`/`Shell_TrayWnd`。进程名：`GetWindowThreadProcessId` + `QueryFullProcessImageNameW`。图标：`WM_GETICON`/`GetClassLongPtr(GCLP_HICON)` → 32×32 PNG（`image` crate）。DPI：`GetDpiForWindow`。可调尺寸：`WS_THICKFRAME`。
2. 过滤规则抽成纯函数 `fn is_capturable(attrs: &WindowAttrs) -> bool`，便于单测。
3. `events.rs`：独立线程 `SetWinEventHook(EVENT_OBJECT_CREATE..EVENT_OBJECT_NAMECHANGE 与 EVENT_OBJECT_LOCATIONCHANGE、EVENT_OBJECT_DESTROY、EVENT_SYSTEM_MENUPOPUPSTART/END, WINEVENT_OUTOFCONTEXT)` + 消息循环；只处理 `idObject == OBJID_WINDOW`；`LOCATIONCHANGE` 按窗口节流 50 ms；输出 `WindowEventRaw` 到通道。
4. `group.rs`：`fn window_group(root: isize) -> Vec<GroupMember>`：同 PID、可见、且 `GetWindow(GW_OWNER)` 链可达 root，或类名 `#32768`（菜单）且属于同线程；返回每个成员相对 root **客户区**原点的偏移。
5. `examples/list_windows.rs` 打印列表与 5 秒内的事件。

## 接口
```rust
pub struct WindowAttrs { pub hwnd: isize, pub title: String, pub process: String, pub pid: u32,
  pub rect: Rect /*屏幕坐标 客户区*/, pub dpi: u32, pub resizable: bool, pub minimized: bool,
  pub style: u32, pub ex_style: u32, pub cloaked: bool, pub class: String }
pub fn list_windows() -> anyhow::Result<Vec<WindowAttrs>>;
pub fn window_icon_png(hwnd: isize) -> Option<Vec<u8>>;
pub fn is_capturable(a: &WindowAttrs) -> bool;
pub enum WindowEventRaw { Created(isize), Destroyed(isize), Moved(isize), Title(isize), MenuStart(isize), MenuEnd(isize) }
pub fn spawn_event_watcher() -> anyhow::Result<(WatcherHandle, crossbeam_channel::Receiver<WindowEventRaw>)>;
pub struct GroupMember { pub hwnd: isize, pub offset_x: i32, pub offset_y: i32, pub w: u32, pub h: u32 }
pub fn window_group(root: isize) -> Vec<GroupMember>;
```
（`Rect` 自行在本 crate 定义，与 rd-capture-win 同字段）
