## 目标
`rd-input-win` 把“窗口客户区坐标系”中的鼠标/键盘/文本事件注入到目标窗口，必要时先把窗口置前。

## 实现步骤
1. 坐标映射纯函数：`client_to_absolute(hwnd_client_origin_screen, x, y, virtual_desktop_rect) -> (i32, i32)`，归一化到 0..65535（`MOUSEEVENTF_ABSOLUTE | MOUSEEVENTF_VIRTUALDESK`）。客户区原点由 `ClientToScreen` 实时获取（需进程 Per-Monitor-V2 DPI 感知，在 T-015 的 manifest 中设置；本任务在 example 中用 `SetProcessDpiAwarenessContext` 设置）。
2. `mouse.rs`：move / button down/up（左右中、X1/X2）/ wheel（垂直 `WHEEL_DELTA` 倍数、水平 `MOUSEEVENTF_HWHEEL`）。
3. `focus.rs`：`ensure_foreground(hwnd)`：已前台直接返回；否则 `AllowSetForegroundWindow(ASFW_ANY)` → 模拟一次 Alt 按下抬起 → `SetForegroundWindow`；500 ms 内对同一窗口不重复尝试。返回是否成功。
4. `keyboard.rs`：扫描码注入（`KEYEVENTF_SCANCODE`，extended 位 `KEYEVENTF_EXTENDEDKEY`）；文本注入 `KEYEVENTF_UNICODE`（UTF-16 逐码元，代理对两次）。
5. 安全键：Ctrl+Alt+Del 无法注入，忽略并返回错误；Win 键允许。
6. 断开时 `release_all()`：抬起所有记录为按下的键与鼠标键（防止卡键）。

## 接口
```rust
pub struct Injector; impl Injector {
    pub fn new() -> Self;
    pub fn mouse_move(&mut self, hwnd: isize, x: i32, y: i32) -> anyhow::Result<()>;
    pub fn mouse_button(&mut self, hwnd: isize, x: i32, y: i32, button: u32 /*0左1右2中3X1 4X2*/, down: bool) -> anyhow::Result<()>;
    pub fn wheel(&mut self, hwnd: isize, x: i32, y: i32, dx: i32, dy: i32) -> anyhow::Result<()>;
    pub fn key(&mut self, scancode: u32, extended: bool, down: bool) -> anyhow::Result<()>;
    pub fn text(&mut self, s: &str) -> anyhow::Result<()>;
    pub fn release_all(&mut self);
}
pub fn ensure_foreground(hwnd: isize) -> bool;
pub fn client_to_absolute(origin: (i32, i32), x: i32, y: i32, vdesk: (i32, i32, i32, i32)) -> (i32, i32);
```

## 风险与回滚
- 以管理员权限运行的窗口无法从普通权限注入（UIPI）：记录为已知限制，返回错误码。回滚 revert。
