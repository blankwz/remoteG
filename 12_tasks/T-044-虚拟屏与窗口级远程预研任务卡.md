## 接口
```rust
// rd-vdisplay 预期形态（一期验收锚点）
let vd = VDisplay::open(FitSpec::phone_ratio(PhoneModel::from_config(&cfg)?))?; // 建屏+登记基准至1080宽每10点一档
vd.set_width(540)?;                 // 基准档；窄窗口放不下时 set_width(档位) 换档
// 换档后 agent 侧：捕获尺寸变化 → FramePipeline::reconfigure() → 下一帧 IDR（现有机制，无需流重协商）
drop(vd);                           // 撤屏后轮询等显示器真消失，再恢复其他屏窗口位置
```

## 已知风险
- 驱动签名：便携 zip 无法零摩擦，需一次管理员授权装驱；微软签名路线需 Dev Center + EV 证书，当前不可行（报告 §1.3）。
- Win11 ARM 等部分系统拒绝非 WHQL 显示驱动（issue #465，边缘）；实机验证清单覆盖。
- WGC 捕获管线对虚拟屏的适配未验证；CI 已知 WGC 在无 GPU 环境有「API 可用但零帧」问题，虚拟屏可能新增类似边界（报告 §3 风险 5）。
- 换比例后推流端须主动重建捕获会话（remoteG 自研双端，无 snug「UU远程 要重选一次屏幕」问题，但重建时序需 e2e 锁住）。
