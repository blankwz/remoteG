## 实现步骤
1. 根 `Cargo.toml`：`[workspace] resolver = "2"`，`members = ["crates/*", "apps/rd-agent", "tools/clarity-bench"]`，`exclude = ["apps/rd-controller"]`；`[workspace.dependencies]` 统一声明：`tokio`(full)、`quinn`、`rustls`、`rcgen`、`prost`、`prost-build`、`anyhow`、`thiserror`、`tracing`、`tracing-subscriber`、`bytes`、`serde`(derive)、`serde_json`、`zstd`、`qoi`、`windows`（版本取实现时最新稳定版，写入 Cargo.lock）。
2. Windows 专属 crate（capture/input/window/term 的 conpty、agent、clarity-bench）：`windows` 依赖放在 `[target.'cfg(windows)'.dependencies]`，模块内容用 `#[cfg(windows)]` 包裹，保证 macOS 上 `cargo check --workspace` 通过。
3. `rd-proto`：`build.rs` 用 `prost-build` 编译 `../../proto/rd.proto`；`lib.rs`：`pub mod v0 { include!(concat!(env!("OUT_DIR"), "/rd.v0.rs")); }`。在 build.rs 里用 `protoc-bin-vendored` 提供 protoc，避免本机安装。
4. `ci.yml`：`windows-latest` 跑 `cargo fmt --check`、`cargo clippy --workspace -- -D warnings`、`cargo test --workspace`；`macos-latest` 跑 `cargo check --workspace`。
5. `README.md`：构建命令、目录说明（引用架构文档路径）。
