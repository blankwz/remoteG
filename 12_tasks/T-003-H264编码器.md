## 目标
`rd-encode` 提供统一 `VideoEncoder` trait，输入 BGRA 帧输出低延迟 H.264 Annex-B AU；优先硬编，失败回退 OpenH264。

## 实现步骤
1. `frame.rs`：定义 `RawFrame`（BGRA、宽高、stride、pts_us）。BGRA→I420 转换用 `yuv` 或 `dcv-color-primitives` crate（选其一，SIMD）。
2. `h264_openh264.rs`：`openh264` crate；配置：Baseline/Constrained，`usage = ScreenContent`，无 B 帧，码率可调，关键帧间隔 = 无限（按需 IDR），`rate_control = Bitrate`。
3. `h264_ffmpeg.rs`（feature `ffmpeg`，默认开启于 Windows）：`ffmpeg-next`；依次尝试 `h264_nvenc`、`h264_qsv`、`h264_amf`、`h264_mf`；参数：`zerolatency`/`ll` 预设、`bf=0`、`g` 很大、CBR/VBR 低延迟、像素格式 NV12（硬编）。
4. `lib.rs`：`create_best(cfg)` 按上述顺序探测（每个尝试编码 1 帧测试），返回第一个成功的；`EncoderInfo` 记录名称。
5. 宽高必须偶数：奇数时右/下补 1 像素（记录在 `EncodedAu.crop`）。
6. `examples/encode_file.rs`：生成 300 帧合成画面（滚动文字色块）→ `out.h264`，可用 `ffplay out.h264` 播放。

## 接口
```rust
pub struct EncoderConfig { pub width: u32, pub height: u32, pub fps: u32, pub bitrate_kbps: u32, pub prefer_hw: bool }
pub struct EncodedAu { pub data: Vec<u8> /* Annex-B */, pub keyframe: bool, pub pts_us: u64 }
pub struct EncoderInfo { pub name: &'static str, pub hardware: bool }
pub trait VideoEncoder: Send {
    fn encode(&mut self, frame: &RawFrame, force_key: bool) -> anyhow::Result<Option<EncodedAu>>;
    fn set_bitrate(&mut self, kbps: u32) -> anyhow::Result<()>;
    fn reconfigure(&mut self, width: u32, height: u32) -> anyhow::Result<()>; // 尺寸变化，下一帧 IDR
    fn info(&self) -> EncoderInfo;
}
pub fn create_best(cfg: &EncoderConfig) -> anyhow::Result<Box<dyn VideoEncoder>>;
```

## 测试要求
- 新增 `tests/encode.rs`：OpenH264 编码 30 帧，首帧 keyframe、输出以 `00 00 00 01` 开头；`reconfigure` 后首帧为 keyframe；奇数尺寸可编码。
- 运行：`cargo test -p rd-encode`；`cargo run -p rd-encode --example encode_file`

## 验收标准 DoD
- [ ] 无 ffmpeg 环境（`--no-default-features`）下 OpenH264 路径可用、测试通过
- [ ] 有 ffmpeg DLL 时，本机能选中至少一个硬编（日志打印 `EncoderInfo`）
- [ ] 1080p 单帧编码耗时：硬编 < 5 ms、OpenH264 < 20 ms（example 打印统计）
- [ ] `out.h264` 能被 ffplay 正常播放，文字可辨认

## 风险与回滚
- ffmpeg 开发库获取：使用 BtbN 的 LGPL shared 构建，设置 `FFMPEG_DIR`；若阻塞超过 0.5d，先交付 OpenH264 路径，硬编转为遗留项并告知 Orchestrator。
- 回滚：revert；`create_best` 可强制 OpenH264（`prefer_hw=false`）。

## 禁止事项
- 不链接 GPL 版 ffmpeg（不使用 libx264）；不改其他 crate。
