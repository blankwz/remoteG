## 功能清单

### F1 悬浮工具栏（P0）
连接建立后自动出现在画面顶部，鼠标离开 3s 收起为小圆点，点击展开。

按钮（左→右）：
⚙画质 | 📋常用语 | ⌨虚拟键 | 📸截屏 | 🖥全屏 | 🔒锁屏 | ⌨Ctrl+Alt+Del | ─折叠

### F2 常用语面板（P0）
- 预设 5 条中文短语 + 用户自定义（localStorage，上限 20 条）
- 点击→逐字发送到远程（KEYEVENTF_UNICODE）
- Enter 发送 / Shift+Enter 换行

### F3 虚拟按键面板（P0）
- 修饰键：Ctrl / Alt / Shift / Win（可组合点亮）
- 特殊键：Tab / Esc / Enter / Backspace / Del / Home / End / PgUp / PgDn / ↑↓←→
- 功能键：F1~F12
- 多媒体：音量±/静音/播放暂停
- 系统：Win / Ctrl+Alt+Del / Alt+Tab / Win+D

### F4 左侧窗口列表（P1）
- 远程机所有可见窗口的实时列表（2s 轮询+事件推送）
- 点击→SetForegroundWindow
- 进程图标 + 标题
- 搜索过滤
- 📌 折叠/展开

### F5 画质控制（P1）
- 档位：自动 / 高(20Mbps/60fps) / 中(8Mbps/30fps) / 低(2Mbps/15fps)
- 色彩：彩色 / 黑白（省带宽）
- 分辨率：1:1 / 适配窗口

### F6 截屏（P1）
- 截取当前远程画面 → 保存到本机 Downloads

### F7 快捷键映射（P1）
| 本地 | 远程 |
|---|---|
| Ctrl+Alt+F | 全屏切换 |
| Ctrl+Alt+S | 截屏 |
| Ctrl+Alt+Q | Ctrl+Alt+Del |
| Ctrl+Shift+P | 常用语面板 |
| Ctrl+Shift+K | 虚拟按键面板 |
| Alt+Tab | 远程 Alt+Tab |
| Win+D | 远程显示桌面 |
| 其余 | 全部透传 |

### F8 虚拟鼠标（P2，移动端）
- 触控板模式：单指移动/轻点/双指点/双指滑
- 精确模式：双指捏合放大+减速
- 拖拽模式：长按+拖

### F9 隐私屏（P2）
- 远程显示器黑屏，仅控制端可见画面

### F10 录屏（P2）
- 录制远程画面 → 保存 webm
