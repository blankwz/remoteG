## 目标
控制端持久化身份与设备列表，可用 6 位码配对新设备；把 `conn.rs` 升级为通用连接层（RPC + 事件订阅 + 数据流路由），供 T-020～T-023 使用。

## 实现步骤
1. 身份：`load_or_create_identity(app_data_dir, hostname)`；设备列表 `devices.json`：`[{id(uuid), name, addr("host:port"), fingerprint_hex, added_at}]`（信任即设备列表，使用 `TrustStore` 存指纹 + 自有 JSON 存地址）。
2. `conn.rs` 新增 `DeviceConn`：
   - `connect(addr, expected_fp)` → `open_control` → 发 `Hello{decode_caps, supports_444}`（caps 由前端在启动时通过 `set_decode_caps` 命令上报，前端用 `VideoDecoder.isConfigSupported` 探测）。
   - 后台读循环：带 `req_id` 的响应投递给等待中的 `oneshot`；无 `req_id`（=0）的消息（WindowEvent、StatsReport、Error）广播给订阅者。
   - `rpc(msg) -> Envelope`（5 s 超时）；`subscribe() -> broadcast::Receiver<Envelope>`。
   - 数据流路由：`accept_data`/`accept_bidi` 循环；视频/瓦片帧按 `window_id` 查注册表 `register_window(root_id, Channel)`（子窗口通过 WindowEvent 的 root_id 映射到同一 Channel）；终端按 stream id 查 `register_term(stream_id, Channel)`，未注册先缓存 2 s。
   - 瓦片在 Rust 侧解码（QOI/zstd → RGBA），以 `[帧类型 u8=2][TileHeader][RGBA]` 发给前端；视频原样 `[帧类型 u8=1][VideoHeader][AU]`；失效 `[u8=3][TileHeader]`。
   - `ConnManager` 改为 `HashMap<device_id, Arc<DeviceConn>>`，断线自动移除并向前端发 `device-disconnected` 事件。
3. `commands/devices.rs`：`list_devices`、`pair_device(addr, code, name)`、`remove_device(id)`、`connect_device(id) -> HelloAckDto`、`disconnect_device(id)`、`probe_device(id) -> bool`（2 s 超时连接测试）、`set_decode_caps(caps)`。
   - 配对：`connect(addr, None)` → Hello → 收到 `Error{1}` 后执行 `ControllerPairing` 两轮 → 成功则保存设备（指纹=对端 TLS 指纹）。
4. `Devices.tsx`：设备卡片（名称、地址、指纹前 8 字节、在线圆点）；“添加设备”对话框（地址默认端口 21118，可填 MagicDNS 名，如 `my-pc:21118`；6 位码输入）；点击设备 → `connect_device` → 跳转 `/windows/:id`；错误提示（码错误、锁定剩余时间、无法连接）。

## 接口
```rust
#[tauri::command] async fn pair_device(addr: String, code: String, name: String, ...) -> Result<DeviceDto, String>;
#[tauri::command] async fn connect_device(id: String, ...) -> Result<HelloAckDto, String>;
pub struct DeviceConn; impl DeviceConn {
  pub async fn rpc(&self, msg: envelope::Msg) -> anyhow::Result<Envelope>;
  pub fn subscribe(&self) -> broadcast::Receiver<Envelope>;
  pub async fn send(&self, msg: envelope::Msg) -> anyhow::Result<()>;           // 无需响应
  pub fn send_datagram(&self, b: Bytes) -> anyhow::Result<()>;
  pub fn register_window(&self, root_id: u64, ch: Channel<InvokeResponseBody>);
  pub fn unregister_window(&self, root_id: u64);
  pub fn register_term(&self, stream_id: u64, ch: Channel<InvokeResponseBody>);
  pub async fn term_write(&self, stream_id: u64, data: &[u8]) -> anyhow::Result<()>;
}
```
