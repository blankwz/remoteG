## 分块

### ✅ 块 1：按窗口实测选档铺满（ScreenFit 联动）——3b07172
- 落地：虚拟屏上的根窗口外框构成需求表，窗口开/关/resize 联动集体选档
  （能装下全部窗口的最窄档，可升可降；表空回落基准档）。手动
  `SetDisplayWidth` 语义 = 一次性档位指令，后续自动事件照常重算。
- 结构：`vdisplay.rs` 拆模块（`orch` 引用计数状态机 + `fit_sched` 选档调度线程
  + `mod` 生产 IO）；fit 调度线程走静态 std mpsc（编码线程无 tokio 上下文
  也可触发）+ 250ms debounce 吸收连续 WM_SIZE。
- M-4 清偿：`DisplayHandle` trait + `DisplayFactory` 注入，`Shared` 不再硬绑
  `WindowsBackend`；三个竞态分支（建屏排队归零 / 建屏完成归零撤回 / 撤屏
  与复用交错）用 FakeBackend（rd-vdisplay 新增 `test-util` feature）确定性
  单测 5 条。
- L-2 清偿：删除 protocol.rs `wait_for_incoming` 死重（轮询路径在
  windows_backend）。
- 接线四触发点：register_pipe（开窗）/ apply_viewport（视口适配）/ 编码线程
  FrameStep.resized（窗口自身 resize）/ pipe_cleanup（关窗）。
- e2e t16：开窗升档 / resize 联动 / 关窗回落 / 断开撤屏全链断言（期望值复用
  width_for_windows，驱动缺失判 skip）。**待真机跑**（依赖装驱动机器 + 串行锁）。
- 语义注记：width_for_windows 判定按窗口**外框**（装得下的硬约束是外框不超屏），
  与 width_to_fit 的客户区语义不同（Windows 有边框，两函数各有用途不混用）。

### ✅ 块 2：关闭按钮定位与轻点关闭——1aa6998
- 落地：触屏轻点虚拟屏窗口标题栏关闭钮位置 → 语义化 CloseWindow（免前台
  门控），核对失败回退普通点击。
- proto WindowInfo 附加字段 13-20（线上兼容）：窗口外框 frame_* + 关闭钮
  矩形 close_*；列表顺序显式声明 = Z 序（EnumWindows 语义，从前到后）。
- rd-window-win：`close_button_rect` = 保守内缩矩形（宁小勿大——漏判无害：
  点击落在关闭钮上，普通点击 ≡ 关窗口；误判才危险）+ WM_NCHITTEST 存在性
  验证（HTCLOSE 权威；挂起窗口 200ms 超时保护）。**核心安全论证**：全部
  失败路径（漏判/RPC 失败/核对不过）都退化为普通点击兜底，无一例外。
- 控制端 touch.rs：按下批次拉 Z 序列表构造 WinSnapshot（全局→客户区相对
  换算，与 translator 事件坐标系一致）；release 批判定点关闭 → 新鲜列表
  is_frontmost 用关闭钮的 window+window_frame 核对 → CloseWindow 消息或
  照常补发点击。
- 前端零改动（控制端自治，前端不传 close_button）。
- 单测 8 条（轻点命中/快照跨批次/区域外/降级/换算）。
- 真机验证：**待手测**（§5.10 触屏项）。

### ✅ 块 4：手势翻译与虚拟屏联动——2039b30
- 落地：虚拟屏窗口的触屏手势阈值 scale 从「窗口物理宽/画面 css 宽」切换为
  「虚拟屏档位宽/画面 css 宽」——换档会改变远程侧物理宽度，普通语义的阈值
  逼随档位漂移，按虚拟屏宽取才与手指所见比例一致。
- WindowGroupView 新增 vdisplayWidth prop（null = 非虚拟屏窗口，沿用原语义）；
  Session.tsx 从 VdisplayStateDto 传当前档位宽。
- 惯性滚动手感（1px=1delta 档位）依赖触屏真机，**待手测**不阻塞合入。
