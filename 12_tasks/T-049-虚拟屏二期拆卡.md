## 分块

### 块 1：按窗口实测选档铺满（ScreenFit 联动）
- 现状：一期 `fit_of` 按配置基准档建屏，`SetDisplayWidth` 手动换档。
- 二期：窗口打开到虚拟屏时按**窗口实际客户区**选最佳档（`rd-vdisplay/src/fit.rs` 档位数学已备），窗口尺寸变化联动换档；无窗口时回落基准档。
- 改动面：`apps/rd-agent/src/vdisplay.rs`（选档策略）+ `window_session.rs`（开窗/resize 时机钩子）+ e2e 断言。

### 块 2：关闭按钮定位与轻点关闭
- 现状：`rd-touch-translate` 的 `TouchRegion.close_button` 与 `CloseButton::is_frontmost` 已备，控制端接线时传 None（见 T-047）；被控端无窗口 z 序查询。
- 二期：被控端窗口 z 序枚举（GetWindow + GW_HWNDPREV 走 z 序）随窗口列表下发或随探针核对；控制端手势翻译喂 `close_button`（远程窗口关闭按钮在虚拟屏上的位置由被控端窗口矩形推算）；点关闭 → translator 出 `CloseWindow` 命令 → 现有 CloseWindow 消息。
- 改动面：`crates/rd-window-win`（z 序枚举）+ proto 窗口列表附加字段（附加字段线上兼容）+ 控制端 touch.rs（region 构造带 close_button）。

### 块 3：控制端 App 资源库首页（运行中/全部/搜索）
- 现状：窗口侧栏列当前桌面窗口（WindowSidebar），虚拟屏窗口混在列表里无区分。
- 二期：设备页/会话页新增「资源库」视图——运行中（可立即投屏）/全部应用/搜索过滤；窗口卡片显示图标+标题；点击即在虚拟屏打开（复用 OpenWindow + 块 1 选档）。
- 改动面：`apps/rd-controller` 前端（新页面/组件）+ `commands/windows.rs`（枚举扩展：图标提取 HICON→PNG dataURL）。

### 块 4：手势翻译与虚拟屏联动（最后做）
- 现状：触屏手势全链路已接（T-047），但 region 的 scale 语义是「远程物理宽/画面 css 宽」——对虚拟屏手机比例场景，阈值应按虚拟屏逻辑分辨率取。
- 二期：虚拟屏窗口打开时 region 构造切换为虚拟屏语义（scale=虚拟屏宽/画面 css 宽）；块 2 的 close_button 并入；惯性滚动在虚拟屏场景的 1px=1delta 手感实测定档。
- 改动面：`pages/Session.tsx`（region 参数来源分流）+ `touch.rs`。
