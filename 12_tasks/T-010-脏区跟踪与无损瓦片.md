## 目标
对每个窗口维护 64×64 块网格：识别变化块，块静止 ≥ 300 ms 后产出 QOI/zstd 无损瓦片；块再次变化时产出“失效”标记。这是文字清晰的核心路径（D-004）。

## 实现步骤
1. `dirty.rs`：`BlockGrid::update(frame, hint: Option<&[Rect]>) -> ChangedBlocks`；有 hint 时只比对 hint 覆盖的块；比对用每块 `xxh3` 哈希（`xxhash-rust`）。尺寸变化时重建网格，全部置为“脏”。
2. 每块状态机：`Dirty{since}` → 静止 300 ms → `Refined`（已发无损）→ 变化 → `Dirty` 并输出 `Invalidate`。
3. `tiles.rs`：`TileRefiner::tick(now, frame) -> Vec<TileOut>`：合并相邻待精修块为矩形（行内合并，最大 256×256）；编码：先 QOI，若 QOI 大小 > zstd(level 1) 大小则用 zstd-BGRA；每 tick 字节预算 `budget_bytes`（由调用方根据码率给定），超出预算的留到下一 tick（优先离鼠标/最近输入点近的块：接口提供 `focus_point`）。
4. 失效：对已 Refined 又变化的区域输出 `TileOut{fmt:255}`（矩形合并同上）。

## 接口
```rust
pub struct BlockGrid; impl BlockGrid { pub fn new(w: u32, h: u32) -> Self; pub fn update(&mut self, f: &RawFrame, hint: Option<&[Rect]>) -> usize /*changed count*/; }
pub struct TileOut { pub x: u16, pub y: u16, pub w: u16, pub h: u16, pub fmt: u8, pub data: Vec<u8> }
pub struct TileRefiner; impl TileRefiner {
    pub fn new(w: u32, h: u32, still_ms: u32) -> Self;
    pub fn on_frame(&mut self, f: &RawFrame, hint: Option<&[Rect]>, now: Instant) -> Vec<TileOut>; // 返回失效
    pub fn tick(&mut self, f: &RawFrame, now: Instant, budget_bytes: usize, focus: Option<(u32,u32)>) -> Vec<TileOut>;
}
```
（`Rect` 在 `frame.rs` 定义；若 T-003 未定义，本任务在 `dirty.rs` 内定义并 `pub use`）
