在 Windows CI 上自动验证 Agent 主流程：鉴权、窗口列表、视频首帧、无损瓦片逐像素正确、输入注入、终端回显。

- 修改：`.github/workflows/ci.yml`（Windows job 增加 `cargo test -p rd-agent --test e2e -- --test-threads=1`）

## 实现步骤
1. `common`：启动 `clarity-bench testwin --mode static`（`CARGO_BIN_EXE` 不跨 crate，改为 `cargo build -p clarity-bench` 后从 `target/debug` 定位）；启动 Agent（`--no-tray --listen 127.0.0.1:0 --print-port --test-pair-code 123456 --config-dir <tempdir>`）；客户端完成配对。
2. 用例：
   - `list_contains_testwin`：WindowList 中有标题含 `clarity-bench` 的窗口。
   - `open_window_keyframe`：OpenWindow 后 2 s 内收到 keyframe 视频帧；用 `openh264` 解码成功。
   - `tiles_pixel_exact`：静止 1 s 后收集瓦片拼图，与 `rd-capture-win` 直接抓取的源图在已覆盖区域逐像素一致。
   - `fit_resizes_window`：发送 Viewport(800×600, dpr 1) → 下一个 keyframe 尺寸为 800×600。
   - `click_injection`：MouseButton(100,100) 按下抬起 → testwin 标题 `clicks=1 last=100,100`。
   - `terminal_echo`：OpenTerminal(cmd.exe) → 写 `echo rd_e2e\r\n` → 3 s 内收到 `rd_e2e`。
   - `unopened_window_input_rejected`：对未打开窗口点击，testwin 计数不变。
   - （T-027 后）`menu_child_added`：在 testwin 上右键（testwin 需提供右键菜单）→ 收到 CHILD_ADDED。
3. CI：GitHub Actions `windows-latest` 有交互桌面会话，WGC 可用；若 WGC 在 CI 不可用，用例检测 `is_supported()` 后 `skip` 并打印原因（不得静默通过）。

## 测试要求
