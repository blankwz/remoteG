## 目标

## 实现步骤
1. 命令：`open_window(device_id, window_id, fit, max_fps, on_frame: Channel) -> OpenWindowAckDto`（先 `register_window` 再 `rpc(OpenWindow)`）；`close_window`；`set_viewport(device_id, window_id, css_w, css_h, dpr)`；`subscribe_group_events(device_id, root_id, Channel)`（CHILD_ADDED/REMOVED/MOVED、Error 12、StatsReport）。
2. `SessionStore`：每个窗口组的状态（根尺寸、子窗口表、fit 模式、zoom、stats）。
3. `WindowGroupView`：容器 `position: relative`；根窗口与每个子窗口各一个 `{video canvas, tile canvas}` 叠层（tile canvas 在上，透明背景）；子窗口按 `offset / effectiveDpr` 绝对定位。帧分发：按帧头 `window_id` 找对应 `H264Decoder` 或 `TileLayer`。
4. `TileLayer`：帧类型 2 → `putImageData` 到 tile canvas；类型 3 → `clearRect`。视频重新 IDR（尺寸变化）时清空整层。
5. 1:1 规则：canvas 像素尺寸 = 视频尺寸；CSS 尺寸 = 像素 / `effectiveDpr`，其中 `effectiveDpr = devicePixelRatio / zoom`。
6. 模式（工具栏）：
   - Fit（默认）：`ResizeObserver` 监听容器 → `set_viewport(css_w, css_h, dpr / zoom)`（150 ms 去抖）；收到 Error 12 自动切换 Scale 并提示“该窗口无法调整尺寸”。
   - Scale：不改远端，CSS 等比缩放到容器（`object-fit: contain` 效果），整数倍时 `image-rendering: pixelated`。
   - Native：1:1，容器滚动。
   - 缩放倍率 zoom ∈ {100%, 150%, 200%}：Fit 下远端窗口变小、本地放大显示，用于小屏看清字；200% 使用 pixelated。
7. 标签栏：窗口标题 + 关闭；URL 参数 `?open=<id>` 自动打开；断线时显示遮罩“已断开，重连中”，自动重连 3 次后重开窗口。
8. HUD：fps、解码 ms、RTT、kbps、编码 codec、当前模式；快捷键 `Ctrl+Shift+H` 切换。
9. 调试命令（clarity-bench 用）：`Ctrl+Shift+S` 把当前根窗口的 video+tile 合成画面以原始像素导出 PNG 到下载目录（`canvas.toBlob` + Tauri `fs`/`dialog` 插件）。
