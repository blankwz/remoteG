## 实现步骤
1. `package-agent.ps1`：`cargo build -p rd-agent --release` → 复制 exe + ffmpeg LGPL DLL + LICENSE 到 `dist/rd-agent-<ver>-win64.zip`。
2. `release.yml`：tag `v*` 触发；Windows 打 Agent zip + 控制端 MSI；macOS 打 dmg（未签名，README 写明右键打开）；上传 GitHub Release。
3. 兼容性手测：记事本、VS Code、Chrome、Windows Terminal、资源管理器、Office（如有）、一款 Qt 程序 × DPI 100%/150% × 控制端 Windows/macOS，记录到 `09_test/兼容性.md`（通过/问题/截图路径）。
4. 清晰度：每个控制端用 clarity-bench 跑一次，`text_exact_ratio` 记录到 RUN_LOG（目标 100% 静止）。
5. 延迟：tailnet 直连与 DERP 各测一次，记录 P95。
6. 连续使用 1 小时稳定性（VS Code 编码 + 终端），记录崩溃/内存增长。
