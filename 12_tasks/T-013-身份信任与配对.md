## 目标
`rd-security` 提供：身份证书加密持久化、信任列表、基于 SPAKE2 的 6 位配对码配对（两端共用），以及失败锁定。

## 实现步骤
1. `store.rs`：`load_or_create_identity(dir, name)`：文件 `identity.bin`；Windows 用 DPAPI `CryptProtectData`（`windows` crate）加密，macOS/iOS 用 `keyring` crate 存密钥（或 `security-framework`），其他平台明文 + 文件权限 600 并打印警告。目录：Agent `%LOCALAPPDATA%\rd\`，控制端由调用方传入（Tauri app data dir）。
2. `trust.rs`：`TrustStore`（`trusted.json`：`[{fingerprint_hex, name, added_at, last_seen}]`），`is_trusted`、`add`、`remove`、`touch`；写入用临时文件 + rename 保证原子。
3. `pairing.rs`：
   - Agent：`PairingCode::generate()` → 6 位数字（`rand`，CSPRNG），有效 5 分钟，一次性。
   - 协议：使用 `spake2` crate（Ed25519 group），identity A=`"rd-controller"`, B=`"rd-agent"`，密码 = 配对码；双方交换 SPAKE2 消息后派生 key，用 HMAC-SHA256(key, 本端指纹 ‖ 对端指纹) 互相确认（放在 PairRequest/PairResult 的 `spake2_msg` 之后的第二轮：可复用同两个消息类型，第二轮 `spake2_msg` 字段承载 MAC），确保码正确且绑定双方 TLS 指纹（防中间人）。
   - 失败计数：5 次失败锁定 10 分钟（Agent 侧全局）。
4. 状态机用纯 Rust 实现，不依赖网络，便于测试。

## 接口
```rust
pub fn load_or_create_identity(dir: &Path, name: &str) -> anyhow::Result<rd_transport::Identity>;
pub struct TrustStore; impl TrustStore {
    pub fn open(path: &Path) -> anyhow::Result<Self>;
    pub fn is_trusted(&self, fp: &Fingerprint) -> bool;
    pub fn add(&mut self, fp: Fingerprint, name: &str) -> anyhow::Result<()>;
    pub fn remove(&mut self, fp: &Fingerprint) -> anyhow::Result<()>;
    pub fn list(&self) -> Vec<TrustedPeer>;
    pub fn touch(&mut self, fp: &Fingerprint) -> anyhow::Result<()>;
}
pub struct AgentPairing; impl AgentPairing {
    pub fn new() -> Self;
    pub fn new_code(&mut self) -> String;            // 6 位，旧码作废
    pub fn current_code(&self) -> Option<(String, Instant /*expires*/)>;
    pub fn on_message(&mut self, msg: &[u8], local_fp: &Fingerprint, peer_fp: &Fingerprint) -> PairStep;
}
pub struct ControllerPairing; impl ControllerPairing {
    pub fn start(code: &str, local_fp: &Fingerprint, peer_fp: &Fingerprint) -> (Self, Vec<u8> /*first msg*/);
    pub fn on_message(&mut self, msg: &[u8]) -> PairStep;
}
pub enum PairStep { Send(Vec<u8>), Done, Failed(PairError) }
pub enum PairError { WrongCode, Expired, Locked { until: Instant }, Protocol }
```
